# Church branding

`cc-mark.svg` is the unchanged vector artwork extracted from `ccfw/CC Icon Black.ai`.

Run `npm run icons` from `mobile` to regenerate:
- `cc-header.png`: transparent header mark.
- `fwcc-icon.png`: opaque 1024 × 1024 RGB app icon on white, also used for the web favicon.
- `fwcc-adaptive.png`: transparent Android foreground and monochrome silhouette, inset for adaptive masks.

The corresponding SVG files are generated by the same script. The source Illustrator files remain in the repository's `ccfw` folder.
